# Harnest

> 당신이 승인한 기준으로, 될 때까지 스스로 고치는 AI.

Harnest는 사용자의 실제 질문·답 기록으로 채점 절차를 만들고 검증한 뒤, 그 절차를 동결한 채 문서를 반복 개선하는 웹 관제실입니다. 규범 정의는 [SPEC.md](SPEC.md), 설계 근거는 [PHILOSOPHY.md](PHILOSOPHY.md), 원샷 대비 실측 기록은 [experiments/delta-01](experiments/delta-01/PROTOCOL.md)에 있습니다.

## 현재 플래그십

**인수인계·온보딩 문서 — “나 없이도 돌아가는 문서”**

1. 실제로 받았던 질문과 당시 답을 입력합니다.
2. 마지막 1/3은 자동 홀드아웃으로 분리해 문서 생성·수정 과정에서 숨깁니다.
3. 시험관이 순서·변별력·안정성·꼼수 내성을 검증합니다.
4. 사용자가 블라인드 A/B 캘리브레이션을 마친 뒤 채점 절차 전체를 승인·동결합니다.
5. 원샷 문서를 라운드 0 기준선으로 채점하고, 가시 케이스의 실패 사유를 바탕으로 반복 개선합니다.
6. 결과에서 개선 곡선과 시작·종료 홀드아웃을 확인합니다. 홀드아웃 질문은 가시 세트에도 같은 질문이 있었는지에 따라 **반복/신규**로 구분해 보고합니다.

개발용 시간표 템플릿도 같은 엔진을 사용합니다. 완전 결정적 채점 경로와 체크포인트·재개 동작을 모델 호출 없이 점검하기 위한 내부 테스트베드입니다.

## 모의 모델과 Gemini BYO

| 모드 | 용도 | 데이터 경로 |
|---|---|---|
| 모의 모델 | 무료 데모와 결정적 회귀 테스트. 실제 문서 품질의 증거가 아님 | 브라우저 내부에서만 실행 |
| Gemini BYO | 실제 모델로 시험관 검증·채점·생성 실행 | API 키는 `localStorage`에만 저장되고 요청은 브라우저에서 Gemini로 직행 |

검증과 실행은 모델을 여러 번 호출합니다. 인수인계 템플릿의 정상 라운드당 호출 수는 `문서 변이 1회 + 가시 케이스 수 × 2회(responder+grader)`이며, 시험관 배터리와 시작·종료 홀드아웃 채점은 별도 호출입니다. 채점 JSON 형식이 잘못된 경우에만 형식 수정 요청을 한 번 추가합니다.

## 실행

Node 22+가 필요합니다.

```bash
npm install
npm run dev            # http://localhost:5173
```

백엔드는 선택 사항입니다. 현재 웹 앱은 백엔드가 없어도 브라우저에서 완결되고, 결과를 사용자가 명시적으로 기록할 때만 로컬 API를 호출합니다.

```bash
cd apps/api
pip3 install -r requirements.txt
python3 -m uvicorn main:app --port 8000
```

전체 검사:

```bash
npm run typecheck
npm test
npm run build
cd apps/api && python3 test_api.py
```

## 구조

| 경로 | 역할 |
|---|---|
| `packages/contracts` | 인터뷰·Evaluation Pack·시험관·루프 계약과 동결 다이제스트 |
| `packages/loop-engine` | 브라우저 반복 개선 엔진: 시드 RNG, 매 라운드 체크포인트, 일시정지·재개, 정체 종료 |
| `templates/handover` | 플래그십 질문·컴파일·시험관·케이스 채점·문서 생성 |
| `templates/timetable` | 완전 결정적 내부 테스트 템플릿 |
| `apps/web` | React SPA: 위저드 → 승인 → 관제실 → 결과 |
| `apps/api` | FastAPI + SQLite 결과 저장 API. 임의 코드를 실행하지 않음 |

## 구현 상태

구현됨:

- 판정 절차 전체의 SHA-256 동결과 다른 팩·템플릿 체크포인트 재개 차단
- 시험관 검증, 블라인드 캘리브레이션, 같은 다이제스트의 실패 고착
- 승인·검증·캘리브레이션·실행 식별자·홀드아웃의 IndexedDB 스냅샷 복원
- 채점 JSON 엄격 파싱, 형식 수정 1회, 형식 오류 라운드의 체크포인트 오염 방지
- 가시/홀드아웃 동일 분량 hard gate와 실격·0점 구분
- Gemini 인증 오류 즉시 실패, 네트워크·429·5xx 재시도, 요청 타임아웃

계획됨:

- 정식 Evaluation Pack·루프 스펙과 서버 기록 계약
- 무료 체험 프록시, 인증·쿼터, PostgreSQL 기반 호스팅
- 커스텀 프로바이더 연결 테스트와 브라우저 CORS 실측
- pairwise 채택, 빔 탐색, 서버 측 홀드아웃 봉인은 현재 범위에 포함하지 않음
